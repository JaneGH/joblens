# JobLens

## Problem

Android developers searching for jobs have to manually read and compare many job descriptions.

It is difficult to understand:

- which jobs are a good match;
- which skills are requested most often;
- which skills the developer is missing;
- what to prepare for a specific interview.

## Solution

JobLens is an Android application that uses AI to transform unstructured job descriptions into structured job requirements.

The application compares those requirements against the developer's profile and helps identify job matches, skill gaps, and interview preparation priorities.

## MVP

The user can:

1. Paste a job description.
2. Analyze the description using AI.
3. Review and edit the extracted information.
4. Save the job locally.
5. View saved jobs.
6. Create a developer profile.
7. Compare their profile against a job.
8. See matching and missing skills.
